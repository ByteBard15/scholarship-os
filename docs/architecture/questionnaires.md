# Questionnaires

Applications own questionnaires, ordered questions, and revision-friendly answers. Questions track required state, type, options, and limits. Answers retain source type/entity, confidence, agent metadata, and prefill-run provenance.

Factual answers supported by an Effective Profile or accepted research may be filled. Long-form subjective content remains `suggested` or `needs_review`; only a human can approve it. A questionnaire becomes complete only when all required questions are resolved.
